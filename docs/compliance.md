# Compliance

- **COPPA** — Aura is how platforms prove over13 without collecting children's data.
- **GDPR** — data minimization by architecture: raw ID retention is 60 seconds,
  purpose-limited, and deletion is receipted. There is no profile to export because none exists.
- **No ID retention** — the design target for every regulation that asks
  "why are you keeping this?" is: we're not.
- Age-assurance laws (US state laws, UK Online Safety Act) ask for proof of age —
  Aura returns the boolean and discards the evidence.
